## 배경
운영진 '설정' 모듈의 첫 화면이다. 법정공휴일과 운영진이 등록하는 추가 휴일(A34)을 연간 달력으로 보고, 추가 휴일을 등록·삭제하고, 법정공휴일을 바로 가져온다. 선행 백엔드는 BE-3n(#148, A95: 특일 정보 API 동기화)이다.

## 주요 결정 (사용자 결정, F72)
- 설정 모듈 > 공휴일, 연간 달력 12개(4열 × 3행), 팝업 없이 오른쪽 '선택한 날' 칸에서 추가·삭제.
- 선택한 날은 구분·이름·삭제 가능 여부만(설명 문장 없음), 구분은 배지 대신 텍스트 색(달력 색과 맞춘 F14 예외).
- 날짜를 고르지 않으면 그해 모든 공휴일 목록, 삭제는 확인 창, 가져오기는 토스트로 연도별 건수.
- 추가·삭제·가져오기는 `mentoring.settings.manage`가 있을 때만.
- 공휴일이 아닌 토·일은 구분을 '주말'로 보인다(평일과 구분, 추가 휴일 등록은 가능).

## 발견한 문제와 해결
- 날짜를 고르지 않았을 때 그해 공휴일 목록이 화면보다 길어진다. 목록 칸에 화면 높이 제한과 자체 스크롤을 두었다.
