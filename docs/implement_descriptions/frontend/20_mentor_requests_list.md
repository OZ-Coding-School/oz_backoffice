### 화면 규칙 (F43·F44)
- **탭:** 대기·승인·반려·취소·전체. 기본은 대기이고 건수는 고른 기수 기준이다(A76).
- **기수 필터:**
  - 보기는 내 배정 기수 전체(비활성 포함, 최근 시작 순)다. 맨 위는 '전체 기수'다.
  - 데스크톱은 탭 오른쪽, 태블릿·휴대폰은 탭 아래 전체 폭이다.
- **행·카드:**
  - 신청일, 주제, 시간·기수, 신청자(1:1이면 이름, 팀이면 팀 이름), 희망 일시, 상태를 보여 준다.
  - 희망 일시는 대기면 이른 희망 일시와 '외 N', 승인이면 확정 일시, 반려·취소면 '—'다.
- **배지:** 받은 신청 메뉴에 전체 기수의 승인 대기 건수(99+)를 모든 메뉴 위치에 단다.
- 행에서 상세로 가는 링크는 상세 화면과 함께 FE-9b에서 넣는다.

## 주요 결정 (사용자 결정)
- **F43:**
  - PR은 BE-2j → 9a → 9b로 나눈다. 주소는 `/mentor/requests`다.
  - 기수 필터를 넣고, 보기는 내 배정 기수 전체로 한다. 건수는 고른 기수 기준이다.
- **F44:** 표·카드 시안대로 하고, 받은 신청 메뉴에 대기 건수 배지를 모든 메뉴 위치에 단다.
- **A76:** 기수 이름·수강 상태와 기수 필터는 백엔드에서 보완한다. 희망 일시별 겹침은 표시하지 않는다.

## 발견한 문제와 해결
- 메뉴 배지를 화면 읽기 프로그램이 모두 '안 읽음'으로 읽었다. 메뉴 항목에 `badgeLabel`을 두어 채팅은 '안 읽음', 받은 신청은 '대기'로 읽게 했다. 더보기는 안의 배지가 한 종류일 때만 그 말을 쓴다.
