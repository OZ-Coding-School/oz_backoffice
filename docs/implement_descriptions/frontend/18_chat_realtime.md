### 화면 규칙 (F41)
- **[채팅]·[팀 채팅]:**
  - 방 목록에서 그 상대와의 방을 찾아 바로 간다.
  - 방이 없으면 버튼을 숨긴다. 방은 신청 안내로 생긴다(A74).
- **안 읽음 배지:**
  - 방별 안 읽음 수의 합이다. 100 이상이면 '99+'이다.
  - 채팅이 휴대폰 더보기 안에 있으면 더보기 탭에도 합을 단다.
- **실시간 수신:**
  - 로그인한 동안 탭마다 연결 하나를 둔다.
  - 받은 메시지는 열린 대화와 방 목록(미리보기·순서·안 읽음)에 바로 반영한다.
  - 재전송이 없으므로 다시 연결되면 방 목록·열린 방을 다시 조회한다(A58).

## 주요 결정 (사용자 결정)
- **F41:**
  - [채팅]은 그 상대와의 방으로 간다(방이 없으면 숨김).
  - 배지는 모든 메뉴 위치에 단다.
  - 수신은 직접 만든 fetch 스트림 파서로 한다(새 의존성 없음).
  - 끊기면 3초부터 최대 30초로 늘려 다시 연결한다.

## 발견한 문제와 해결
- 테스트에서 스트림 이벤트가 방 목록 캐시보다 먼저 와서 반영되지 않았다. 목록을 불러온 뒤 이벤트를 밀어 넣는 `pushableSse` 도우미를 만들었다.
- 세션 상세 테스트에서 메뉴의 '채팅' 링크와 [채팅] 버튼 이름이 겹쳤다. 테스트는 링크 주소로 구분한다.
