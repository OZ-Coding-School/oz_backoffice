## 배경
F92에 따라 F91 디자인 형식(페이지 머리 아이콘 타일·섹션 카드·설정 줄·요약 칸·상세 머리 카드, 둥근 2xl + 그림자)을 이 모듈 화면에 적용한다. 기능·API·주소는 바꾸지 않는다.
