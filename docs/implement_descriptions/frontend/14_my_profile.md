### 화면 규칙 (F37·A72)
- **내 정보:**
  - 휴대폰은 가운데 4자리를 가린다(`010-****-1234`).
  - 활성 기수(수강 중, 없으면 가장 최근)의 과정·기수·수강 상태·기수 기간을 보여 준다.
  - 정보 칸은 데스크톱 4열, 태블릿 2열, 휴대폰 1열이다.
- **[비밀번호 재설정]:** 비밀번호 계정(`available`)에만 보인다. 누르면 창을 열고, 보낸 링크가 없을 때만 바로 보낸다.
- **창:**
  - 링크를 보낸 동안(SENT) 5초마다 상태를 확인한다.
  - 인증되면(VERIFIED) 입력칸을 켜고 남은 시간을 보여 준다.
  - 새 비밀번호 아래에는 규칙 충족을, 확인 칸 아래에는 일치 여부를 입력하는 대로 보여 준다(사용자 요청).
  - 저장하면 창을 닫고 '비밀번호를 바꿨어요'를 알린다.
  - 다시 보내기는 보낸 지 1분이 지나야 켜진다.
- **링크 화면:** 토큰을 한 번만 확인한다. 완료 문구는 '이메일 인증이 완료되었습니다.'(사용자 결정)이다.
- **메뉴:** 하단 탭은 메뉴 5개라 모두 보인다. '더보기'는 메뉴가 6개가 되는 FE-6b에서 넣는다(F36).

## 발견한 문제와 해결
- 기존 재설정은 코드 방식이라 링크 방식을 쓰려면 백엔드가 필요했다. BE-2f(#98)로 먼저 넣었다.
- 링크는 한 번만 쓸 수 있어서, React 개발 모드의 이중 실행에도 두 번 부르지 않도록 확인 요청을 Query로 묶었다(다시 시도·다시 조회 없음).
- 전체 테스트를 돌리면 목록·다시 보기·변경 흐름 테스트가 부하로 5초를 넘기는 일이 생겼다. 이전(#89)처럼 그 테스트들에만 20초 제한을 두었다.
