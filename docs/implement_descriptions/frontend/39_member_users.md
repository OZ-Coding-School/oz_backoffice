## 주요 결정 (사용자 결정, F71)
- 승인된 계정만, 종류 탭 + 검색 + 상태 필터, 행을 누르면 슬라이드 패널.
- 패널은 계정 + 종류별 연결 정보 + 이력, 수정은 없고 머리에 [비활성화]/[활성화]만.
- 수강 기수 기간은 보여 주지 않는다(API에 없음). 강사도 멘토 계정이라 '배정' 섹션으로 보인다.
- Figma: 수강생·멘토·강사·운영진·비활성 예시 패널과 비활성화 확인 창.
