### 화면 규칙 (F42)
- **요약 3칸:**
  - 오늘 멘토링은 오늘 KST 예정·진행 중 세션 수다. 누르면 진행 기록 예정 탭으로 간다.
  - 승인 대기 신청은 대기 신청 수다. 누르면 신청 내역 대기 탭으로 간다.
  - 안 읽은 채팅은 방별 안 읽음의 합이다. 누르면 채팅으로 간다.
  - 휴대폰은 한 줄에 3칸이고, 이름이 길면 두 줄로 넘긴다.
- **멘토링 카드 (전체 폭):**
  - 남은 시간은 만료되지 않은 1:1 계좌(차감 예정)와 팀 계좌(팀 이름)다. 1:1 계좌가 없으면 '아직 지급된 시간이 없어요'다.
  - 다가오는 세션은 예정·진행 중을 이른 순으로 3개 보여 준다. 오늘이면 '오늘' 배지와 [Meet 입장], 진행 중이면 '진행 중' 배지다.
  - 승인 대기 신청은 2개까지 보여 주고 희망 일시 수를 적는다.
  - 항목은 세션 상세·신청 상세로 간다.
  - 둘 다 없으면 '예정된 멘토링이 없어요'와 [멘토링 신청]이다.
  - 수강이 끝났거나 기수가 1:1·팀을 모두 막으면 [멘토링 신청]을 숨긴다.

## 주요 결정 (사용자 결정)
- **F42:** 요약 3칸, 멘토링 카드 전체 폭, 다가오는 세션 3 + 대기 신청 2, 요약·항목은 해당 화면으로 간다.
- **A75:** 가까운 순 세션은 프론트에서 고르지 않고 백엔드 정렬(`order=asc`)을 추가해 받는다.
- 오늘 기준은 화면을 연 시각이다. 자정을 넘겨 열어 두면 다시 들어와야 바뀐다.

## 발견한 문제와 해결
- 세션 목록이 최신순만 지원해 `limit=3`이면 가장 먼 세션이 왔다. 사용자 결정으로 백엔드 정렬을 먼저 추가했다(BE-2i).
- 개발 도중 GitHub Actions가 결제 문제로 멈췄다. 사용자가 저장소를 공개로 바꿔 다시 돌렸다.
- 홈 E2E가 UTC인 CI에서 실패했다. `page.clock`의 가짜 Date에서는 TZDate가 브라우저 시간대로 표시하기 때문이다. 실제 Date로는 UTC 브라우저에서도 KST로 표시되는 것을 확인했고, 이 E2E만 브라우저 시간대를 KST로 고정했다.
