### 화면 규칙 (F53)
- **반복:** 한 번·매일·매주. 매주는 요일을 하나 이상 고른다. 하루 종일은 한 번에서만 고르고, 시각 대신 첫 날~마지막 날을 받는다.
- **시작·종료:** 날짜와 시각(30분 단위)을 따로 받는다. 종료를 다음 날로 하면 자정을 넘긴다. 한 번에 24시간까지다. 반복이면 기준 회차이고, 반복 종료일은 선택이다.
- **분류·메모:** 분류는 자유 입력(30자, 비우면 '불가 시간')이고 추천 칩 '본업·강의·휴가·개인 일정'이 있다. 메모는 200자다.
- **충돌:**
  - 저장 응답이 `applied=false`면 충돌 확인 창을 띄운다. 신청은 '대기 신청 → 반려', 세션은 '승인 세션 → 취소·환불'로 보여 준다.
  - [그래도 저장]은 `confirm=true`로 다시 보낸다. 정리한 건수를 알린다.
- **수정·삭제:** 목록 ⋯ 메뉴와 시간표 블록에서 연다. 삭제는 확인 창을 거친다. 이미 시작한 한 번은 메뉴·블록 수정이 없다.
- **창:** 휴대폰은 전체 화면이고 취소·저장이 아래에 고정된다. 태블릿·데스크톱은 가운데 창이다.
- **오류:** 시작한 일정, 범위, 30분 경계, 반복 규칙, 비활성 멘토, 지워진 일정을 문구로 알린다.

## 주요 결정 (사용자 결정)
- **F53:** 종료 날짜를 따로 받는다. 분류는 자유 입력 + 추천 칩이다. 수정은 목록 메뉴와 시간표 블록에서 한다. 휴대폰은 전체 화면 창이다.
