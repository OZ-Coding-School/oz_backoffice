## 배경
학사 모듈의 수강생 화면이다. 처음에는 3분할(과정 → 기수 → 수강생) + 슬라이드 패널로 그렸으나, 상세에 보여 줄 것이 많아 기존 시안대로 **위쪽 필터 목록 + 별도 상세 페이지(탭)**로 바꿨다(F76). 선행 백엔드는 BE-3r 수강생 상세 API(#156, A99)이다.

## 주요 결정 (사용자 결정, F76)
- 목록은 기수 선택 필수 + 상태 + 검색(화면에서 거름), 처음엔 담당 기수 중 첫 기수.
- 상세는 별도 페이지 + 탭 기본 정보·멘토링(출결·행정은 범위 밖), 멘토링 요약 카드는 멘토링 탭에.
- 다른 기수 수강 이력·[멘티 상세 보기]는 넣지 않는다(멘티 상세는 FE-20 때).
- 학사 메뉴 순서는 수강생 · 과정·기수 · HRD 과정.
- 화면을 본 뒤 '묶어 보기'(없음 · 수강 상태 · 가입 상태, `?group=`)를 더함: 표 안의 접는 묶음 머리 + 건수, 처음엔 펼침, 상태 탭과 함께 쓴다(F77). 이어서 묶음 머리를 상태 색의 옅은 배경 + 같은 색 배지로 구분하고, 중도 포기 빨강·조기 취업 초록·기수 이동 주황으로 나눴다(표 안 배지도 같은 색).

## 발견한 문제와 해결
- 최근 신청·세션의 행이 갈 운영진 신청·세션 화면(FE-21)이 아직 없어 누르지 않는 행으로 두었다.
- 스크린샷을 찍는 도중 개발 서버(5173)가 내려가 빌드 결과를 다른 포트로 띄워 찍었다.
