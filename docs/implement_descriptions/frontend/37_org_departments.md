## 주요 결정 (사용자 결정, F69)
- 목록·트리 두 보기, 세그먼트 + 주소 `?view=tree`, 상세·수정은 슬라이드 패널.
- 영향 목록은 백엔드 영향 조회로, 종류별 상자 + 접기·펼치기(처음엔 접힘). 부서 삭제는 막히면 대상 목록과 [닫기]만.
- 권한 저장 확인 창은 '바뀐 권한'(추가·제거 상자)과 '영향받는 대상' 두 섹션.

## 발견한 문제와 해결
- 목록 보기의 팀 행 들여쓰기가 열을 밀어 머리글과 어긋났다 → 행 여백은 같게 두고 이름 칸만 들여 씀.
