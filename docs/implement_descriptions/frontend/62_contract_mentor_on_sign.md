# 62. 계약 화면: 새 사람의 멘토는 계약 완료 때 (A115)

- 상태: PR 진행 중
- 관련 PR: (PR 생성 후 기록)
- 관련 결정: `docs/decisions.md` A115 (A104 변경), F97
- 이전 기록: [61. 행정 업무 › 계약 개편 화면 (F96)](61_contract_screens.md), 백엔드 [113](../backend/113_mentor_on_sign.md)

## 배경
BE-4f(#192)로 새 사람의 멘토 계약은 초안·진행 중에 멘토가 없고 계약 완료 때 같은 사람에 연결되거나 가입 전 멘토가 생긴다. 계약 화면의 안내를 그에 맞춘다.

## 구현 내용
- `labels.ts`: 멘토 없는 초안·진행 중 멘토 계약의 멘토 줄은 '계약 완료 때 연결'. 위저드의 새 사람 안내, `ambiguous_mentor` 문구(취소하고 기존 멘토를 골라 다시 만들기).
- `components/dialogs.tsx`: [계약 완료] 창의 서명된 계약서 안내에 '새 사람의 멘토 계약은 이때 멘토가 정해져요'.
- 테스트: 초안 패널에 '계약 완료 때 연결'이 보이고 [멘토 보기]가 없다.

## 검증
- lint, format:check, typecheck, vitest 429개(UTC·Asia/Seoul), e2e 51개 통과.

## 확인용 데이터
- 개발 DB: 헬스케어 8기 '헬스케어 8기 신규 멘토 계약(새 사람 초안)'(초안, 멘토 없음, 계약자 신규멘토). [진행]에서 원본, [계약 완료]에서 서명본을 올리면 가입 전 멘토 '신규멘토'가 생긴다.

## 남은 작업
- 배정 패널에서 근거 계약 고르기, 실제 화면 Figma 캡처.
