## 주요 결정 (사용자 결정, F85)
- 배정은 멘토 상세 배정 탭 + 패널, 패널은 F68 규칙.
- 고르는 입력은 세그먼트 버튼, 고른 칸은 파스텔로 잘 보이게.
- 계약 패널도 이번 PR에서 F68대로 고친다.
- 화면 확인 중 보완: [배정 추가]는 카드 목록 맨 위의 점선 추가 카드로, '노쇼 1건' 라벨은 '노쇼 단가'로.

## 발견한 문제와 해결
- 처음 시안이 F68(섹션 상자·라벨 줄·머리 버튼·같은 구성의 수정)을 따르지 않아 다시 그렸다. FE-18b 계약 패널도 같은 문제가 있어 함께 고쳤다.
