## 주요 결정 (사용자 결정, F24)
- 새로고침해도 진행 상태를 유지한다(가입 유형·이메일·가입 토큰·휴대폰). 비밀번호·인증코드는 저장하지 않는다.
- 휴대폰 번호는 입력하는 대로 하이픈을 넣는다.
- 완료 화면의 '로그인하기'는 가입한 이메일을 채운 로그인 화면으로 간다.
- 모바일 단계 표시와 카드 배치는 Figma에 먼저 그려 확인했다.

## 구현 세부
- **가입 토큰 저장:** 가입 토큰은 가입에만 쓰는 30분짜리 토큰이라 sessionStorage에 둔다. 로그인 access 토큰은 지금처럼 메모리에만 둔다(A7).
- **토큰 만료:** 만료 1분 전부터는 만료로 보고 '인증 시간 만료' 화면을 보여 준다. 응답이 `signup_session_expired`일 때도 같은 화면이다. '처음부터 다시'는 저장된 상태를 지운다.
- **화면에 보여 주는 오류**

  | 오류 | 표시 |
  | --- | --- |
  | `email_already_registered` | 이메일 칸에 알리고 로그인·비밀번호 재설정 링크 |
  | `phone_already_registered` | 휴대폰 칸 |
  | `invalid_verification_code` | 코드 칸("5번 틀리면 새로 받아야 해요") |
  | 만료·횟수 초과 | 코드 칸 |
  | 429 | 다시 시도할 시각 Alert, 그때까지 버튼 비활성 |
  | `invalid_cohort`·`invalid_password` | 해당 칸 |
  | `phone_verification_required` | 휴대폰 인증 단계로 |
- **멘토 '수강생에게 보일 이름':** 보기에 입력한 실명·닉네임을 함께 보여 준다("실명 (김멘토)"). 닉네임을 고르면 닉네임이 꼭 있어야 한다.
- **완료 문구:** 수강생은 "명단", 멘토는 "계약 정보"로 바꿔 보여 준다.

## 발견한 문제와 해결
- **Figma 모바일 유형 카드:** 카드 높이가 고정이었고, 카드 안 여백 프레임이 100px로 늘어나 글자가 카드 밖으로 밀렸다. 카드는 내용에 맞추고 여백 프레임은 1px로 고쳤다.
- **비밀번호 규칙 아이콘:** 맞지 않은 규칙도 체크 아이콘이었다. Figma처럼 X 아이콘으로 고쳤다.
