### 화면 규칙 (F40·A57·A74)
- **방 목록:**
  - 마지막 메시지 최신순이고, 날짜와 안 읽음 수를 보여 준다.
  - 미리보기는 팀 방만 '보낸 사람: 내용'이다. 삭제된 메시지는 '삭제된 메시지입니다.'다.
- **대화:**
  - 오래된 것부터 보여 주고, 처음과 새 메시지에서는 맨 아래로 내려간다.
  - 위로 올려 이전 50개를 붙여도 보던 자리를 지킨다.
  - 안내 메시지는 가운데 회색 카드, 내 메시지는 오른쪽 보라 말풍선이다.
- **읽음:** 맨 아래까지 보고 안 읽음이 있으면 마지막 메시지 ID로 읽음 처리한다.
- **보내기:**
  - Enter로 보내고 Shift+Enter로 줄을 바꾼다. 한글 조합 중 Enter는 보내지 않는다.
  - 휴대폰은 버튼으로 보내고 Enter는 줄바꿈이다.
  - 2,000자 제한이고 글자 수를 보여 준다.
- **삭제:** 본인 메시지에 마우스를 올리면(휴대폰은 길게 누르면) [삭제]가 나오고, 확인 창을 거친다.
- **빈 상태:** '아직 대화가 없어요 / 멘토링을 신청하면 멘토와 대화할 수 있어요'
- **방 고르기 전:** '대화를 골라 주세요'
- **볼 수 없는 방:** '채팅방을 찾을 수 없어요'
- **멘토 화면:** 방 이름은 수강생·팀 이름이고 아랫줄에 1:1/팀을 보여 준다.

## 주요 결정 (사용자 결정)
- **F40:**
  - PR은 7a 화면 → 7b 실시간으로 나눈다.
  - 멘토 채팅도 같은 화면으로 넣는다.
  - 주소는 `/mentoring/chat`이다.
  - 대화 동작은 시안대로 한다.
- **A74:** 채팅 자격은 신청 이력만 보고, 새 대화 버튼은 두지 않는다.
- 시안의 [세션 보기]·[새 대화]는 넣지 않았다(사용자 확인). 안 읽음 배지(메뉴)는 FE-7b에서 넣는다.

## 발견한 문제와 해결
- 새 대화 상대 목록 API가 부족했다(수강생은 신청 받는 멘토만, 멘토용 명단은 없음). 사용자 결정으로 채팅 자격을 신청 이력으로 바꾸고(BE-2h), 새 대화를 없앴다.
- 메뉴가 늘어 휴대폰 '내 정보'가 더보기로 들어가면서 E2E 경로를 고쳤다.
