## 주요 결정 (사용자 결정, F78)
- 수강생 목록 머리 + 슬라이드 패널, 3초 폴링 후 결과 토스트.
- 대상은 '대상 유형' 드롭다운(전체 · 과정 · 기수)에서 시작해 필요한 선택지만 나타난다(라디오 시안에서 바꿈). 전체는 전체 범위 권한일 때만.
- 동기화 권한이 없으면 실행 섹션을 숨기고, 매핑 실패는 전체 범위 조회 권한일 때만 보인다(서버 규칙과 같음).

## 발견한 문제와 해결
- 결과를 기다리며 effect 안에서 상태를 바꾸는 방식은 린트(`set-state-in-effect`)에 걸려, 실행 버튼 처리 안에서 3초 간격으로 상태를 다시 읽는 반복으로 바꿨다.
