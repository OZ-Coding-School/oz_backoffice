## 배경
FE-5의 두 번째 PR이다. 완료 세션 상세에서 Meet 녹화를 다시 보고, 옆 패널에서 전사본과 스마트 메모를 본다. 녹화 영상은 3시간짜리 서명 링크로 재생한다(A68). 전사 문장은 녹화 시작 시각과 비교해 영상 위치를 구한다(A69).

구현 전에 Figma에 다시 보기를 1440·768·390으로 그렸다. 녹화 정리 중 상태는 1440·390으로 그렸다(F21). 위치는 `Member - 수강생 › Column / 다시 보기 (FE-5b)`이다. 시안의 녹화 이름(시작~끝)을 보여 주려고 백엔드에서 녹화 끝 시각을 먼저 보완했다(BE-2e, A71).

### 화면 규칙 (F35)
- **녹화 묶기:** 녹화 목록을 회의 기록(`conference_record`)별로 묶는다.
  - 영상이 있는 회의만 녹화 시작 순으로 둔다.
  - 2개 이상이면 '녹화 N · 시작 ~ 끝' 선택지를 보여 준다. 끝 시각이 없으면 시작만 보여 준다.
  - 고르면 영상·전사본·스마트 메모를 함께 바꾼다.
- **머리:**
  - 정리 상태 줄('녹화 N분 · 전사본·스마트 메모 정리됨')은 태블릿부터 보인다.
  - [내려받기]는 보고 있는 영상의 `download_url`이다.
- **플레이어:**
  - 재생·일시정지: 가운데 버튼, 화면 클릭, 스페이스
  - 현재/전체 시각, 진행 막대(←/→ 5초)
  - 재생 속도 1×·1.25×·1.5×·2×, 음소거·소리 크기(태블릿부터), 전체 화면
  - 휴대폰은 진행 막대를 컨트롤 위 한 줄로 올린다.
- **전사본 탭:**
  - 문장 위치 = 문장 시각 − 녹화 시작이다.
  - 문장을 누르면 그 위치로 가서 재생한다.
  - 재생 중인 문장을 강조하고, 패널 안에서 따라 내린다.
  - 문장이 아직 없으면 '전사 문장을 정리하고 있어요'를 보여 준다.
- **스마트 메모 탭:** 마크다운을 공용 `<Markdown>`으로 보여 준다. 없으면 '정리하고 있어요'이다.
- **[PDF로 보기]:** 지금 탭 문서의 서명 링크(PDF)를 새 창으로 연다.
- **배치:** 1024 이상은 영상 옆에 패널을 두고 높이를 영상에 맞춘다. 그보다 작으면 영상 아래에 높이 360 패널을 둔다.
- **녹화가 없을 때:** 세션 종료 7일 안은 '녹화를 정리하고 있어요', 지나면 '이 세션은 녹화가 없어요'를 보여 준다.

## 주요 결정 (사용자 결정, F35·A71)
- 회의가 여러 번이면 녹화를 고른다.
- 녹화가 없으면 안내 상자를 보여 준다.
- 내려받기·PDF로 보기는 시안 그대로 둔다.
- 플레이어는 직접 만든 컨트롤로 하고, 속도·소리·전체 화면까지 넣는다.
- 작은 화면은 영상 아래에 패널을 둔다.
- 녹화 이름에 끝 시각을 보여 주려고 백엔드를 보완했다(A71).

## 발견한 문제와 해결
- 녹화 목록에 끝 시각이 없어 시안의 '시작 ~ 끝'을 만들 수 없었다. 사용자 결정으로 BE-2e(#96)에서 `ended_at`을 추가했다.
- 데스크톱에서 패널이 영상보다 길어졌다. 패널을 격자 칸 안에 절대 위치로 두어 높이를 영상에 맞췄다.
- 휴대폰 컨트롤 줄에서 진행 막대가 너무 짧아졌다. 진행 막대를 위 한 줄로 올렸다.
